Як це працює зараз

  • Питання можна поставити тільки в межах готових фільтрів
  • Складніше порівняння вимагає програміста і окремої вигрузки
  • Тисячі сторінок JSON, коди замість назв
  • Реєстри між собою не пов'язані

Як це працює з ДАНО

  • Питання формулюється звичайними словами, без обмежень
  • Асистент сам шукає, зіставляє і рахує
  • У відповідь таблиця, графік, граф зв'язків або файл
  • Prozorro, НАЗК і ЄДР доступні в одній розмові

MCP це як USB-роз'єм для ШІ

Стандарт, що дозволяє під'єднати до асистента зовнішнє джерело даних. Далі він користується ним сам.

Вставити конфіг

П'ять рядків у налаштування асистента. Без ключів API і без реєстрації.

Локальний індекс

Кеш тримає повний зріз закупівель з 2015 року, тому відповідь приходить швидко.

Розумна видача

Асистент отримує компактну вижимку, повні документи підтягує лише за потреби.

claude_desktop_config.json 
{
  "mcpServers": {
    "dano-prozorro": {
      "command": "npx",
      "args": ["-y", "@dano/prozorro"]
    },
    "dano-nazk": {
      "command": "npx",
      "args": ["-y", "@dano/nazk"]
    }
  }
}
