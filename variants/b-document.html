Тисячі сторінок JSON, коди замість назв, реєстри між собою не пов'язані. ШІ вміє це розібрати, але доступу до даних у нього немає.

MCP це як USB-роз'єм для ШІ

Стандарт під'єднання. Він дозволяє дати асистенту зовнішнє джерело даних, і далі той користується ним сам: шукає, бере потрібне, рахує.

Один раз вставити конфіг. Без програмування, без ключів API, без розуміння того, як усе влаштовано всередині.

Локальний індекс і кеш. Асистент отримує компактну вижимку, повні документи підтягує лише тоді, коли вони справді потрібні.

claude_desktop_config.json 
{
  "mcpServers": {
    "dano-prozorro": {
      "command": "npx",
      "args": ["-y", "@dano/prozorro"]
    },
    "dano-nazk": {
      "command": "npx",
      "args": ["-y", "@dano/nazk"]
    }
  }
}
