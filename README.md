# mcpoda

Лендинг і документація проєкту **ПРОЯВ** — двох MCP-серверів, які під'єднують українські відкриті державні дані (Prozorro, НАЗК, ЄДР) до будь-якого ШІ-асистента.

Проєкт Департаменту цифрового розвитку, інформаційної політики та кіберзахисту Одеської обласної державної адміністрації.

> **Статус:** сервери ще не опубліковані. Перелік tools, назви пакетів і URL у документації є чернеткою специфікації, а не працюючим API.

## Що тут лежить

| Шлях | Що це |
|---|---|
| `web/` | Основний сайт: лендинг + документація. Vite + React 19 + Tailwind v4 |
| `archive/variants/` | Три ранні напрямки дизайну статикою, збережені для порівняння |
| `archive/` | Найперший статичний прототип лендингу |

## Запуск

```bash
cd web
npm install
npm run dev     # http://localhost:5173, документація на /docs/
npm run build   # збірка обох сторінок у dist/
```

## Стек

- **Vite 8 + React 19 + TypeScript**
- **Tailwind v4** через `@tailwindcss/vite`, токени в `src/index.css`
- **motion** для морфінгу панелі джерел і появи секцій
- **@paper-design/shaders** — WebGL-шейдер металевого канта на головній кнопці
- **lucide-react** — іконки

Дві сторінки збираються як окремі входи Vite: `index.html` (лендинг) і `docs/index.html` (документація).

## Дизайн

- Темна тема, один акцент `#3d6bff`
- Дисплейний шрифт Unbounded, основний Manrope, моно JetBrains Mono
- Хореографія появи героя: типографіка → сітка → проводи → вузли
- Уся анімація вимикається під `prefers-reduced-motion`
