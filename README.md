# mcpoda

Лендинг і документація проєкту **ПРОЯВ** — двох MCP-серверів, які під'єднують українські відкриті державні дані (Prozorro, НАЗК, ЄДР) до будь-якого ШІ-асистента.

Проєкт Департаменту цифрового розвитку, інформаційної політики та туризму Одеської обласної державної адміністрації.

> **Статус:** два сервери працюють, пакети ще не опубліковані в npm.
> Локально ставляться і працюють: перевірено пакуванням і встановленням у чисту теку.

## Що тут лежить

| Шлях | Що це |
|---|---|
| `servers/prozorro/` | MCP-сервер закупівель: 9 інструментів, локальний індекс, аналітика |
| `servers/nazk/` | MCP-сервер декларацій: 4 інструменти, без локального індексу |
| `PLAN.md` | План роботи з критеріями приймання по кожній фазі |
| `docs/PROOF.md` | Запис реальної сесії: справжні виклики і справжні числа |
| `web/` | Основний сайт: лендинг + документація. Vite + React 19 + Tailwind v4 |
| `archive/variants/` | Три ранні напрямки дизайну статикою, збережені для порівняння |
| `archive/` | Найперший статичний прототип лендингу |

## Запуск

Сайт:

```bash
cd web
npm install
npm run dev     # http://localhost:5173, документація на /docs/
```

Сервери:

```bash
cd servers/prozorro && npm install && npm run build
cd servers/nazk && npm install && npm run build
```

Підключення до асистента, поки пакети не в npm:

```json
{
  "mcpServers": {
    "proyav-prozorro": {
      "command": "node",
      "args": ["/абсолютний/шлях/servers/prozorro/dist/index.js"]
    },
    "proyav-nazk": {
      "command": "node",
      "args": ["/абсолютний/шлях/servers/nazk/dist/index.js"]
    }
  }
}
```

Індекс закупівель збирається окремо і потрібен для аналітики:

```bash
cd servers/prozorro && ./scripts/build-index.sh
```

## Стек

- **Vite 8 + React 19 + TypeScript**
- **Tailwind v4** через `@tailwindcss/vite`, токени в `src/index.css`
- **motion** для морфінгу панелі джерел і появи секцій
- **@paper-design/shaders** — WebGL-шейдер металевого канта на головній кнопці
- **lucide-react** — іконки

Дві сторінки збираються як окремі входи Vite: `index.html` (лендинг) і `docs/index.html` (документація).

## Дизайн

- Темна тема, один акцент `#3d6bff`
- Дисплейний шрифт Unbounded, основний Manrope, моно JetBrains Mono
- Хореографія появи героя: типографіка → сітка → проводи → вузли
- Уся анімація вимикається під `prefers-reduced-motion`
